# UAE Real Estate Platform

A bilingual UAE-focused real estate management platform MVP built with Node.js and Express.

## Features

- Web-based dashboard for property and portfolio management
- Arabic and English UI toggle
- Login flow for staff access
- Property listing and status overview
- Client, lease contract, and commission management sections
- Mobile-friendly UI
- Demo data for UAE property operations

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npm start
   ```

3. Open:
   ```bash
   http://localhost:3000
   ```

## Project structure

- `server.js` — Express API and static server
- `public/index.html` — app entry
- `public/styles.css` — responsive bilingual styling
- `public/app.js` — dashboard and login logic

## Notes

This is an MVP for demonstration and product planning. It is suitable as a foundation for extending into a full production system with database storage, admin workflows, payments, and property documents.
